Courier Booking

Credentials for one-click parcel booking from the Live Orders panel. Saved to MongoDB and they override .env — swap providers or rotate keys with no code changes.

Automated booking is live for Steadfast, Pathao, and RedX when credentials are configured.
Sent as the Api-Key header. Find it in your Steadfast merchant portal under API settings.
Sent as the Secret-Key header. Masked here for safety — retype it to change it.

Pathao booking reads from server environment variables. Set these in your .env file:

  • PATHAO_CLIENT_ID, PATHAO_CLIENT_SECRET
  • PATHAO_USERNAME, PATHAO_PASSWORD
  • PATHAO_STORE_ID
  • PATHAO_IS_LIVE=true for production API

RedX booking reads from server environment variables. Set these in your .env file:

  • REDX_API_TOKEN
  • REDX_PICKUP_STORE_ID (optional)
  • REDX_IS_LIVE=true for production API
Courier engine: Add your API key and secret key to enable one-click parcel booking.
